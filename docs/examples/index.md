# Examples

Real setups, done in a few steps. Each one links back to the concept pages
for the why; here it is only the commands.

- [Express site with TLS](express-site-with-tls.md) — an Express app,
  reachable over HTTPS with an automatic certificate.
- [Docker site on 8080](docker-site-on-8080.md) — a container publishing a
  port, reachable over HTTPS.
- [Claude Code, controlled from your phone](claude-code-remote-control.md) —
  start a session on the machine, drive it from the Claude app.
- [Start Claude from your phone](start-claude-from-your-phone.md) — a session
  kept up on the machine, so you never have to SSH in first.
- [An agent in its own workspace](an-agent-in-its-own-workspace.md) — an
  autonomous agent, isolated in its own account.
